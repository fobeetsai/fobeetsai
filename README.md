## 🚇 專案精選與教學系統 (Featured Projects)

### 🌟 [【線上系統】土木捷運・潛盾隧道整體工程全面術語庫・互動檢索與複習系統](https://fobeetsai.github.io/shield-tunneling/)
> **👉 直接點擊上方連結即可進入線上系統，供學員、工程師與口譯人員直接使用！**

* **收錄規模**：**6,367 條** 中日雙向專門術語（含讀音假名、英文對應、現場防錯與工程定義）。
* **清晰 13 大專業領域**：
  1. 總論與工法規劃 (970 詞)
  2. 地質地層與地下水理 (353 詞)
  3. 潛盾機機構與切羽出土 (212 詞)
  4. 推進導向與線形測量 (547 詞)
  5. 環片襯砌與防水接頭 (156 詞)
  6. 工作井立坑與發到達 (122 詞)
  7. 地盤改良與背填注漿 (540 詞)
  8. 擋土支撐與深開挖邊坡 (679 詞)
  9. NATM山岳隧道與爆破 (329 詞)
  10. 機電設備、電氣與通信 (839 詞)
  11. 安衛環保與防災應變 (821 詞)
  12. 施工管理、品管與監造 (538 詞)
  13. 成本積算與契約法規 (261 詞)
* **核心功能**：
  - 📋 **即時檢索**：支援中文、日文、假名、英文跨欄位快速模糊查詢。
  - 🗂️ **抽認卡複習**：翻面複習、支援鍵盤空白鍵翻面與左右鍵切換、日語語音朗讀。
  - ✍️ **隨堂測驗**：雙向中日情境隨機測驗與即時答對率追蹤。
