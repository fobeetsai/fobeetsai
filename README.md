### 📕 [【線上系統】華語閱讀大師 — 日本人エンジニアのための中国語リーディング＆文法解析](https://fobeetsai.github.io/chinese-reader/)
> **👉 貼上中文文章即得分詞、注音／拼音、HSK 分級與日文語法解說。全部在瀏覽器端完成，不需安裝、不需登入，可直接傳給學員使用。**

* **語法手冊 154 條・17 大分類**：句型公式、日文解說（與日語的語序差異・使用場合）、**例句附注音與拼音**與日文譯文、語音朗讀。可依分類・HSK 等級・關鍵字瀏覽，**支援繁簡互查**。
* **雙標音系統**：拼音與注音可切換，含空韻處理（`shī` → ㄕ）與一聲不帶調號等正字規範。
* **多音字與助詞讀音依語境判斷**：銀行 háng／音樂 yuè、伺服器 **sì** fú qì；`得` de／děi／dé、`著` zhe／zháo／zhuó 自動辨識。
* **日文釋義 100% 覆蓋**：2,066 詞詞彙庫 ＋ 1,000 高頻單字釋義庫 ＋ 約 300 條常用詞組譯義。
* **47,220 詞分詞字典**，採最長匹配並處理過度分詞。
* **👆 懸停字典**：游標移到任一單字即跳出卡片並自動發音，含讀音・HSK 級・詞性・日文釋義・例句；卡片固定於視窗上方不遮擋內文，可拖曳並記住位置。
* **🎯 逐句練習與聽打**：4 種遮蔽模式（遮注音／遮漢字／遮翻譯／挖空）、麥克風朗讀比對準確度、聽打挑戰逐字計分。
* **🔊 自然人聲**：自動優先挑選 Microsoft Natural／Neural 語音（建議使用 Edge 桌面版），可調語速。
* **📥 檔案匯入**：Word・PowerPoint・Excel・PDF・TXT・Markdown・CSV・字幕・HTML，**全在瀏覽器端解析，檔案內容不會上傳**；另支援圖片 OCR。
* **🗂️ 複習庫**：收藏單字與語法點、抽認卡複習、JSON 匯出匯入。
* **離線可用**：分詞・標音・語法分析・範例文章・發音・練習・複習庫皆無需連網。
* **其他**：繁簡轉換、日文／繁中雙語介面、字體大小 6 級調整、6 篇工程師場景範例文章（含人工日文譯文）。
